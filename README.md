## 🚀 Quick Start

### 1. Install Dependencies

```bash
# Create a virtual environment (recommended)
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux

pip install -r requirements.txt
```

### 2. Run the Streamlit Dashboard

```bash
streamlit run app.py
```

Open http://localhost:8501 in your browser.

### 3. Run the Jupyter Notebook

```bash
jupyter notebook notebooks/MugdhaRahate_CyberThreatDetection.ipynb
```

### 4. Generate the Word Report

```bash
python generate_report.py
```

This creates `MugdhaRahate_ProjectReport.docx` in the current directory.

### 5. Run Automated Tests

```bash
pytest tests/ -v
```

## 📚 Dataset

This system is designed for the **CIC-IDS2017** dataset.

**To obtain the real dataset:**
1. Visit https://www.unb.ca/cic/datasets/ids-2017.html
2. Register and download `MachineLearningCSV.zip`
3. Extract a daily CSV (e.g. `Monday-WorkingHours.pcap_ISCX.csv`)
4. Upload it in the **Dataset Explorer** tab

**For immediate testing:** click **Load Sample Dataset** in the Dataset Explorer  
(uses the bundled 20-row synthetic file — see disclaimer above).

## 🔧 Troubleshooting

**`ModuleNotFoundError`** — Run `pip install -r requirements.txt`

**`streamlit: command not found`** — Run `python -m streamlit run app.py`

**No label column error** — Ensure your CSV has a column named `Label`, `Class`, or `Target`

**Model not trained error in Threat Detection** — Go to Model Training first and click Train
